## 简介
本文件系统化梳理控制面板（Control UI）的整体架构、布局设计与核心功能模块，覆盖设备管理、会话监控、系统状态展示等能力，并提供配置管理、权限控制、操作流程、响应式设计与主题定制、用户体验优化等方面的说明。文档同时给出关键流程的时序图与类图，帮助开发者与运维人员快速理解与落地。

**更新** 本版本重点介绍了基于React和shadcn/ui的现代化UI组件系统，包括新的布局架构、组件设计和状态管理。

## 项目结构
控制面板现已演进为"网关侧服务 + React前端 + 多平台集成"的三层架构：
- 网关侧：提供静态资源分发、安全策略、WebSocket 接入点与 RPC 能力
- 前端：基于React + shadcn/ui + Radix UI的现代化组件系统，提供聊天、节点、配置、会话、技能、日志等视图
- 多平台：macOS 应用通过本地/远程隧道解析仪表盘 URL；Electron 提供桌面集成与 IPC 能力

## 架构总览
控制面板采用"网关即服务 + 现代化前端 + 多平台集成"的架构：
- 网关负责静态资源与安全策略，WebSocket 提供实时 RPC 与事件
- 前端通过React Router组织页面，shadcn/ui组件提供一致的UI体验
- 状态管理基于Zustand，提供类型安全的全局状态
- macOS/Electron 提供本地/远程隧道与桌面集成能力

### 组件A：网关控制 UI 服务
职责与特性
- 静态资源路由：对常见扩展名直接返回 404，未知路径回退到 SPA
- 安全策略：严格 CSP，禁止内嵌与内联脚本，仅允许必要的字体/样式来源
- WebSocket：直连网关，支持聊天、会话、配置、日志等 RPC
- URL 规范化：自动将 ws/wss 转 http/https，拼接 basePath，令牌放入片段

```mermaid
SpaFallback --> ApplySec["设置CSP/XFO/NOSNIFF/Referrer"]
ApplySec --> WSConn["建立WS连接(握手)"]
WSConn --> Done(["完成"])
```

- 响应式设计：移动端优先的布局，减少不必要的重排

## 故障排除指南
常见问题与定位建议
- 仪表盘无法打开
  - 确认网关已启动且监听端口可用
  - 检查绑定模式与本地/远程隧道是否正确
- 令牌泄露风险
  - 使用 URL 片段传递令牌，避免查询参数
  - 避免在命令行输出或剪贴板中暴露令牌
- 非安全上下文（HTTP）导致 WebCrypto 不可用
  - 使用 HTTPS 或本地回环地址打开
  - 仅在受控场景启用"允许非安全认证"
- 设备配对失败
  - 首次连接需批准；本地连接自动批准
  - 查看 pending 列表并批准对应请求
- 会话异常
  - 使用会话过滤/搜索定位问题会话
  - 检查会话钩子上下文与代理/工具策略
- 组件渲染问题
  - 检查shadcn/ui组件的导入和配置
  - 确认Tailwind CSS配置正确
- 状态管理问题
  - 检查Zustand store的初始化和订阅
  - 确认状态更新的类型安全性
