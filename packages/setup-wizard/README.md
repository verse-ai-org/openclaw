# @openclaw/setup-wizard

Setup wizard UI component for OpenClaw.

## Installation

```bash
pnpm add @openclaw/setup-wizard
```

## Usage

```typescript
import { SetupWizard } from '@openclaw/setup-wizard';

export function App() {
  return <SetupWizard />;
}
```

## Development

```bash
pnpm dev      # Watch mode
pnpm build    # Build
pnpm type-check  # Type check
```
