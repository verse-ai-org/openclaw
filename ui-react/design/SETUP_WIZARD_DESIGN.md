# OpenClaw Setup Wizard - 设计说明

## 📋 设计概览

这是一个产品级的 Setup Wizard UI 设计，遵循 Apple Music 的简洁高级风格。整个流程分为 5 个步骤，预计用时 3 分钟。

## 🎨 设计理念

### 核心原则

- **简化** → 一次只问一个问题，避免信息过载
- **引导** → 用人话而不是技术术语
- **验证** → 提供智能默认值，用户可直接下一步
- **完成** → 进度可视化，用户知道还要多久

### 视觉风格

- **配色**：Apple 风格的蓝色系（#007aff 为主色）
- **背景**：柔和渐变（#f8f9fa → #e9ecef）
- **卡片**：白色背景，圆角 24px，柔和阴影
- **排版**：清晰的层级，充足的留白
- **动效**：渐变按钮，微妙的阴影提示可交互性

## 📱 完整流程

### Step 0 - 欢迎屏幕（Welcome）

**目标**：快速建立信任，明确预期

**关键元素**：

- 大 Logo（🦞 emoji）
- 清晰的标题和描述
- 3 分钟快速设置的承诺
- 明确的行动按钮
- 可选的登录路径

**设计特点**：

- 进度条：0/5（空）
- 大渐变按钮吸引注意力
- 登录链接作为次要选项

---

### Step 1 - 安全提示（Security）

**目标**：建立安全意识，不制造恐慌

**关键元素**：

- 警告图标（⚠️）
- 简单的安全清单（✓ 符号）
- "了解更多"链接（可选深入）
- 同意复选框

**设计特点**：

- 用清单而不是长段落
- 提供可选的详细信息链接
- 清晰的同意状态

**进度**：1/5

---

### Step 2 - AI 模型选择（AI Model Selection）

**目标**：简化选择，提供推荐

**关键元素**：

- 三个模型卡片
- Claude 卡片突出显示（推荐、蓝色边框、渐变背景）
- 简单的描述（不要技术细节）
- 快速选择按钮

**设计特点**：

- 推荐项用 ⭐ 标记和蓝色高亮
- 卡片式设计便于扫描
- 每个选项都有明确的"选择"按钮

**进度**：2/5

---

### Step 3 - API 密钥输入（API Key Setup）

**目标**：降低技术门槛，提供清晰指导

**关键元素**：

- 三步骤指导（1️⃣ 2️⃣ 3️⃣）
- 一键打开网站按钮
- 密钥输入框（隐藏显示）
- 实时验证按钮

**设计特点**：

- 分步骤指导，每步独立
- 一键打开网站（不要用户手动复制链接）
- 密钥隐藏显示（安全性）
- 实时测试连接反馈

**进度**：3/5

---

### Step 4 - 可选功能（Optional Features）

**目标**：提供扩展功能，但不强制

**关键元素**：

- 三个功能卡片（复选框）
- 简单描述
- 分离的"设置"按钮
- 提示信息（可以后续修改）

**设计特点**：

- 全部可选（复选框，不是必填）
- 简单描述（用户能理解的语言）
- 分离设置（不要在这里填表单）
- 强调可以后续修改

**进度**：4/5

---

### Step 5 - 完成设置（Success Screen）

**目标**：确认完成，提供多个后续路径

**关键元素**：

- 成功图标（✅）
- 设置摘要卡片
- 编辑设置按钮
- 下一步建议（多个选项）
- 主要行动按钮（开始聊天）

**设计特点**：

- 成功反馈（✅ 大符号）
- 设置摘要（用户可以验证）
- 多个行动选项（不强制一个路径）
- 可编辑（返回修改）
- 帮助链接（教程、FAQ）

**进度**：5/5 ✓

---

## 🎯 设计亮点

### 1. 信息架构

- 每个步骤只关注一个主要任务
- 清晰的进度指示（进度条 + 数字）
- 随时可以返回修改

### 2. 用户体验

- 智能默认值（推荐 Claude）
- 一键操作（打开网站、测试连接）
- 实时反馈（连接测试）
- 可选项不强制

### 3. 视觉设计

- 大量留白（Apple Music 风格）
- 柔和渐变背景
- 圆润的卡片设计
- 清晰的色彩层级

### 4. 可访问性

- 清晰的对比度
- 大字体（易读）
- 清晰的按钮状态
- 简单的语言

## 📝 文案原则

- 使用第二人称（"你的"而不是"用户的"）
- 简短清晰（避免长句子）
- 用 emoji 增加亲切感
- 提供具体的时间预期（"3 分钟"、"2 分钟"）
- 强调可选性（"可以跳过"、"以后可以添加"）
